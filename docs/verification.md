## 数据库权限覆盖

SQL 测试在单个事务中创建两名临时用户，分别验证本人读取 / 写入 / 更新 / 删除、跨用户读取不可见、跨用户更新 / 删除影响 0 行、伪造所有者插入与变更归属被拒绝、普通用户不能修改招聘事实、非法状态值被数据库约束拒绝，以及 11 张业务表全部启用 RLS。事务最终全部回滚，没有永久测试用户或测试数据。

浏览器测试只恢复本次临时操作的卡片，没有清空其他已有个人标记。UI 测试涉及的本机访客标记也已恢复，避免后续手动导入时重新带入测试状态。

## 已持久化的云端设置

Organization 为 Free，项目位于新加坡。Data API 开启，新表默认自动授权关闭，自动 RLS 开启。匿名登录、手动身份绑定、邮箱确认三个开关均在保存后重新读取验证为开启。

Site URL 当前为 `http://127.0.0.1:4173/`。允许的回调包含 127.0.0.1 / localhost 的 4173 和 5173 端口，以及本仓库 GitHub Pages 子路径。正式部署到其他地址后必须补充对应回调，并更新 Site URL。
