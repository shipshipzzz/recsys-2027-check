# 全国覆盖与岗位附表工程说明

本轮只改工程。招聘事实、专业、地点、集团目录和岗位附表分别由 data/soe.json、soe-screening.json、soe-locations.json、soe-directory.json、soe-opportunities.json 维护。附表不进入 SQL；原有卡片 ID、来源 ID、历史和十张公共表字段映射保持原协议。岗位附表需要人工审核后绑定 screeningDigest，不能以重算摘要代替审核。

## 日期与资格

当届评估与事实匹配、存在日期范围和可见来源时，核查日早于 RECHECKED 不再降级日期。专业依据与可行动判断独立。待核近 21 天节点出现在近期提醒及“临期待核”筛选中，历史资料不进入当届提醒。

匹配的岗位附表优先提供日期。主节点从尚未过期且非历史、非已结束的岗位中选最近截止；9/30 岗位结束后可继续提示 10/25 岗位。列表逐岗显示专业、工作地、截止范围、来源、投递限制和风险。实习与正式校招分开，历史实习不关闭正式校招。全部已核子集节点过去时只提示其他岗位与新批次另核，不宣称整个机构已停止招聘。

无时刻的日期只按北京时间日界线更新状态，不显示虚构的官方 23:59 截止。24:00 在次日零点到期，23:59:59 按精确秒判断。浏览器每分钟更新，跨截止后重新选择最近岗位。当前事实或来源变动会撤回旧附表的肯定判断。

## 搜索、覆盖和地区

简称、英文简称和集合别名从集团目录读取；同一个“四大行”或“三桶油”别名可以关联多个有记录的集团。总行/总部筛选仅依靠 hqEntryIds，是线索而非资格保证。全国机构覆盖区明确展示已核范围、待核事项和未检查状态；空入口组不生成可投卡片。

地区默认全国。动态城市仅从匹配且当前的岗位或招聘范围评估中提取。待核线索开关默认关闭；开启后无独立地点依据的记录有独立标签、零地区分。已知其他城市的岗位和其他方向的城市不能借此扩展到所选城市。静态 item.xian 标签不再渲染。原参考分收起，数值和排序权重未修改。

## 独立岗位进度

recsys:soe-position-progress:v1 只存岗位 ID 与“待处理 / 已投递 / 不考虑”。不使用旧父卡状态键，不写云端、不参与账号状态同步，也不随账号切换迁移。旧卡标记仅表示入口状态；仍有待处理子岗的卡片继续显示在主列表。岗位进度可单独导出 JSON；存储受限时提示仅内存可用，仍可导出。共享设备上的所有本机使用者共享这一岗位进度，界面明确标记“仅本机保存”。

## 加载和构建边界

Vite ?url 将五份完整 JSON 发出为带内容哈希的静态资产；不生成第二份维护源，不删历史。SOE 冷启动在页面 JS 加载后增加五个并行同源 JSON 请求，单批最多等待 8 秒；不带凭据、不跟随重定向，不访问外部招聘网站。失败交给 bootstrap 显示可恢复的重新加载按钮。推荐算法页不增加数据请求。

原 24 小时资料缓存和云端刷新保持不变；静态基线加载后才验证缓存/云端完整性，旧缓存或云端缺少新增 ID 时保留完整发布基线。首次加载静态数据失败时不能靠旧缓存绕过基线检查，因此不承诺首次断网可启动。浏览器 HTTP 缓存可复用带哈希静态文件，未加入 Service Worker。

并行编辑期间若两份新附表尚不存在，代码允许空默认值，且不创建或覆盖维护文件。正式 data:check 和 build:check 仍要求五份维护文件与资产完整。

原 JS 门槛保持全部 210 KiB、单页 155 KiB，CSS/HTML 不变。新增 JSON gzip 门槛为全部与单页各 200 KiB，原始字节总量上限 2 MiB。初始现有数据实测约 75.7 KB gzip，预留全国扩容空间；新增事实完成后仍须重新实测。JSON 不是免费的体积转移，完整冷启动字节数应同时查看 JS 与 JSON。

构建门禁遍历 manifest 的 assets 引用和全部实际资产，检查 JSON 解析、路径、密钥模式、gzip/原始字节预算；逐字节与五份维护源对照，防止遗漏历史或残留旧构建。release.json.json_assets 保存每份 JSON 的 SHA256。部署验收遍历全部 JS/CSS/JSON，对照本地字节、JSON MIME 与发布摘要，缺少资产不能从计数中消失。没有在本轮执行任何线上验收、发布或云端写入。

## 验证

纯函数测试覆盖昨日来源、临期待核、日界线、独立截止推进、历史实习、事实变化降级、别名引用、城市待核、本机存储、同源超时和数据契约。浏览器使用合成证据、全新隔离上下文并拦截外部请求，覆盖桌面/手机筛选、两岗位日期、父卡与子岗状态、重载保存、导出和加载恢复。合成证据只存在于测试模块和网络夹具，不写入维护资料。

历史审查测试按当时的覆盖范围验证；同一天新增研究不再被旧 reviewedOn 误判成旧报告必须包含的全量最新资料。最终结果和限制记录在 test-results/national-engineering-result.md。

主执行者复核补充：组合关键词逐词跨集团别名与岗位字段匹配。已投递/不考虑或过期的子岗不再占据下一待办截止；仍可在明细中查看原日期。入口个人状态筛选保持原含义，不因子岗存在绕过用户显式筛选。
